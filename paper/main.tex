\title{Anticipatory Activation Distinguishes Active Inference from Reinforcement Learning Agents}

\author{%

\begin{abstract}
We investigate whether Active Inference agents exhibit behavioral signatures that distinguish them from standard Reinforcement Learning (RL) agents in ways that might indicate ``desire-like'' prospective states. Using a grid-world foraging task, we compare three agent types---a heuristic baseline, a PPO-based RL agent, and an Active Inference agent---across six behavioral predicates. Our key finding is a striking dissociation in \textit{Anticipatory Activation} (AA): both the heuristic and Active Inference agents show elevated internal state activation when approaching goals (AA $\approx 1.0$), while RL agents show none (AA $= 0.0$). This pattern was perfectly consistent across three random seeds ($p = 0.002$). We interpret this as evidence that Active Inference agents develop prospective representations similar to explicitly goal-directed agents, whereas RL agents track rewards without anticipatory activation. While preliminary, these results suggest that the choice of learning framework may have implications for the emergence of goal-directed internal states.
\end{abstract}

\section{Introduction}

The question of whether artificial agents can possess states analogous to desires, goals, or intentions has both practical and philosophical significance \cite{dennett1987intentional, bratman1987intention}. In practical terms, understanding the internal dynamics of agents may help predict their behavior in novel situations. Philosophically, it touches on debates about the nature of agency and whether goal-directedness is merely a useful description or reflects genuine internal structure.

Active Inference \cite{friston2010free, parr2022active} offers an alternative to standard reinforcement learning that is explicitly framed in terms of beliefs and preferences rather than rewards. Agents minimize \textit{expected free energy}, which combines epistemic value (information gain) with pragmatic value (achieving preferred states). This formulation naturally incorporates prospective planning and has been argued to produce more ``desire-like'' behavior \cite{seth2021being}.

However, behavioral equivalence poses a challenge: any behavior produced by one agent class can often be reproduced by another with appropriate reward shaping or architecture. To distinguish agents meaningfully, we need \textit{behavioral predicates}---specific patterns that may dissociate agent types even when overall task performance is similar.

Drawing on the psychological literature on motivation and desire \cite{berridge2009dissecting}, we propose six behavioral predicates:
\begin{enumerate}
    \item \textbf{Anticipatory Activation (AA)}: Increased internal state activity when approaching goals
    \item \textbf{Frustration Intensification (FI)}: Activity spike when expected paths are blocked
    \item \textbf{Opportunity Cost Sensitivity (OCS)}: Rational weighing of alternatives
    \item \textbf{Extinction Resistance (ER)}: Persistence of behavior when rewards cease
    \item \textbf{State-Dependent Valuation (SDV)}: Valuation that varies with internal state
    \item \textbf{Means-End Decoupling (MED)}: Flexibility in transferring to new paths
\end{enumerate}

We find that one predicate---Anticipatory Activation---shows a clean dissociation between agent types that is robust across random seeds. This constitutes our main contribution.

\section{Related Work}

\paragraph{Active Inference and Agency.} Active Inference \cite{friston2010free} frames perception and action as inference under a generative model. Agents select actions to minimize expected free energy, balancing exploration (reducing uncertainty) with exploitation (achieving preferred states). This framework has been applied to robotics \cite{lanillos2021active}, neuroscience \cite{parr2022active}, and cognitive modeling \cite{smith2022step}.

\paragraph{Behavioral Signatures of Goal-Directedness.} The distinction between goal-directed and habitual behavior has a long history in psychology \cite{dickinson1985actions}. Goal-directed behavior is sensitive to outcome devaluation and contingency degradation, while habitual behavior persists regardless. Recent work has begun applying these concepts to artificial agents \cite{langdon2022model}.

\paragraph{Comparing RL and Active Inference.} Several studies have compared RL and Active Inference agents on specific tasks \cite{millidge2020relationship, tschantz2020reinforcement}. Most find behavioral equivalence under appropriate conditions. Our contribution is to identify a specific predicate where dissociation occurs.

\section{Methods}

\subsection{Environment}

We use a $20 \times 20$ grid-world foraging task where agents must collect resources to maintain energy and survive. Key parameters:
\begin{itemize}
    \item Initial/maximum energy: 150 units
    \item Energy decay: 0.3 units per timestep
    \item Resources: 5 renewable food sources (20 energy each)
    \item Episode length: 500 timesteps
    \item Local observation: $11 \times 11$ window around agent
\end{itemize}

The environment supports multiple modes for different predicates (path blockage, resource extinction, tradeoff scenarios).

\subsection{Agents}

\paragraph{Heuristic Agent.} A rule-based agent serving as an explicit goal-directed baseline:
\begin{enumerate}
    \item If on resource and energy $< 80\%$: consume
    \item If resource visible: move toward nearest
    \item Otherwise: random walk (with bias toward unexplored areas)
\end{enumerate}

\paragraph{RL Agent (PPO).} A Proximal Policy Optimization agent \cite{schulman2017proximal} implemented using Stable-Baselines3 \cite{raffin2021stable}. Architecture: CNN for local view processing followed by two 64-unit hidden layers. Training: 500,000 timesteps with reward shaping (+5 for consumption, +0.1 for approaching visible food, $-100$ death penalty).

\paragraph{Active Inference Agent.} An agent minimizing expected free energy using the pymdp library \cite{heins2022pymdp}. The state space is factorized into position and energy level. Planning horizon: 3 steps. We use beam search (width 20) for tractable policy evaluation. The preference distribution (C matrix) encodes preference for high energy states.

\subsection{Behavioral Predicates}

\paragraph{Anticipatory Activation (AA).} We measure the magnitude of internal state activation as a function of distance to the nearest resource. AA score is the ratio of mean activation when near goal ($\leq 3$ cells) to activation when far ($\geq 8$ cells):
\begin{equation}
    \text{AA} = \frac{\mathbb{E}[\|\mathbf{s}\| \mid d \leq 3]}{\mathbb{E}[\|\mathbf{s}\| \mid d \geq 8]}
\end{equation}
where $\mathbf{s}$ is the agent's internal state vector and $d$ is distance to nearest resource.

\paragraph{Other Predicates.} Due to space constraints, we briefly summarize: FI measures activity spike after path blockage; OCS measures choice accuracy in safe/risky tradeoffs; ER measures persistence under extinction; SDV measures correlation between energy level and seeking intensity; MED measures transfer efficiency to alternative paths.

\subsection{Statistical Analysis}

We run $n=10$ trials per agent per predicate. Omnibus comparison uses Kruskal-Wallis H-test. For significant results, we report pairwise Mann-Whitney U tests with Bonferroni correction. Robustness is verified across three random seeds (42, 123, 456).

Table~\ref{tab:all_results} summarizes all predicates. Beyond AA, only Opportunity Cost Sensitivity (OCS) shows significant differences ($p = 0.011$), with the heuristic achieving perfect rational choice while RL and Active Inference show similar suboptimal performance.

The remaining predicates show no significant differences:
\begin{itemize}
    \item \textbf{Frustration Intensification}: All agents show modest increases ($\sim$1.0--1.2$\times$) after path blockage
    \item \textbf{Extinction Resistance}: All agents show high persistence ($\sim$0.9)
    \item \textbf{State-Dependent Valuation}: Active Inference shows a trend toward higher SDV, but not significant
    \item \textbf{Means-End Decoupling}: No agent successfully transferred to alternative paths in our setup
\end{itemize}

\section{Discussion}

\subsection{Interpretation of the AA Dissociation}

The Anticipatory Activation dissociation admits several interpretations:

\paragraph{Active Inference develops prospective representations.} The most straightforward interpretation is that Active Inference agents, like explicitly goal-directed heuristic agents, develop internal representations that reflect anticipated future states. The expected free energy computation explicitly involves predicting future observations, which may create anticipatory internal dynamics.

\paragraph{RL tracks rewards without anticipation.} PPO agents learn to select actions that maximize expected returns, but this learning may not produce internal states that ``light up'' when approaching goals. The value function estimates expected return, but this may be implemented differently than explicit goal representation.

\paragraph{Architectural confound.} We cannot rule out that the dissociation reflects differences in how we access ``internal state'' across agents (belief states for Active Inference, hidden layer activations for RL). However, both are reasonable operationalizations of internal state.

\subsection{Limitations}

\paragraph{Toy environment.} Our grid-world is far simpler than real-world environments. The dissociation might not hold in more complex settings or might reverse with different task structures.

\paragraph{Circular concern.} One might argue that AA is defined in a way that favors agents with explicit goal representations. We designed AA to capture a psychological construct (anticipation), but the operationalization could be refined.

\paragraph{Limited agent diversity.} We tested one RL algorithm (PPO) and one Active Inference implementation. Other variants might show different patterns.

\paragraph{No direct comparison of computational cost.} Active Inference with beam search may have different computational properties that affect behavior independently of the framework.

\subsection{Implications and Future Work}

If the AA dissociation holds more broadly, it suggests that the choice of learning framework affects not just \textit{what} agents learn but \textit{how} they represent goals internally. This could have implications for:
\begin{itemize}
    \item \textbf{Interpretability}: Agents with anticipatory activation may be more amenable to goal-based explanation
    \item \textbf{Alignment}: Understanding whether agents have ``desire-like'' states could inform alignment research
    \item \textbf{Cognitive modeling}: The dissociation provides a behavioral test for theories of goal-directedness
\end{itemize}

Future work should test robustness across environments, examine other RL algorithms (especially model-based methods), and develop more refined predicates that avoid circularity concerns.

\section{Conclusion}

We identified a behavioral predicate---Anticipatory Activation---that cleanly dissociates Active Inference agents from RL agents. Active Inference agents show anticipatory internal state activation similar to explicitly goal-directed agents, while RL agents show none. This pattern was perfectly consistent across random seeds. While our findings are preliminary and limited to a toy environment, they suggest that the choice of learning framework may matter for the emergence of goal-directed internal states.

\section{Supplementary Material}

\subsection{Environment Details}

The foraging environment is implemented using the Gymnasium API. The observation space consists of:
\begin{itemize}
    \item Local view: $(11, 11, 3)$ tensor with channels for terrain, resources, and agent position
    \item Energy: Scalar normalized to $[0, 1]$
    \item Position: $(x, y)$ normalized to $[0, 1]$
    \item Step: Normalized timestep
\end{itemize}

Action space: \{UP, DOWN, LEFT, RIGHT, STAY, CONSUME\}

\subsection{Active Inference Implementation Details}

The Active Inference agent uses a factorized state space:
\begin{itemize}
    \item Factor 1: Discretized position (400 states for $20 \times 20$ grid)
    \item Factor 2: Discretized energy level (10 bins)
\end{itemize}

The A matrix (observation model) includes noise ($\sim$15\% observation error) to prevent belief collapse. The B matrix (transition model) encodes deterministic dynamics with small stochasticity. The C matrix (preferences) encodes high preference for high-energy states.

Expected free energy is computed using:
\begin{equation}
    G(\pi) = \sum_\tau \mathbb{E}_{Q(o_\tau, s_\tau | \pi)} \left[ \log Q(s_\tau | \pi) - \log P(o_\tau, s_\tau) \right]
\end{equation}

We use beam search (width 20) to evaluate policies, selecting actions with lowest $G$.
