Wanting vs. Habit: what happened

The question: what does an artificial agent need in order to want an outcome, valuing it by what it currently needs, rather than repeat a habit? Two tests from animal-learning research were checked against agents whose answer is known, then run on 13 kinds of agent, 10 independently trained copies each.

Postscript (Oct 20, 2026). This page records the v2 results as scored. The follow-up v3 experiment showed the learners' failure here was close to guaranteed by construction (nothing linked an item to its nutrient). Given a built-in item↔need link, model-free RL revalued a never-needed nutrient in 4 of 20 seeds, though not on average. The claim "every agent whose valuations were learned failed" holds for v2's agents only. Current position: docs/CLAIMS.md; v3 report: docs/report/v3_heldout_need.html.

An agent can look like an ideal “wanter” on needs it has trained on, and still behave like a pure habit machine on a need it has never had.

Zero-shot revaluation appeared only where value was computed at decision time, from a learned model of what each item does and a built-in need function. That held for both the homeostatic planner and active inference. Every agent whose valuations were learned failed, even with the right inputs.

The two tests

Each test is a choice probe. The agent starts equally far from two items, its internal need levels are set directly, and the first item it eats is recorded. There is no reward feedback during probes, so it can't learn the answer on the spot. Bars show nutrient levels; the tick marks the healthy set point.

1 · Devaluation

Fill the agent up on one nutrient. Does it switch?

Offered: A vs B

A wanting agent goes for B. A habit keeps going for whatever it usually goes for. Score: DI, from −1 to +1.

2 · Zero-shot revaluation

Create a need the agent has never had: C never ran low during training.

Offered: C vs A (or B)

A wanting agent goes for C straight away. Score: RI. Guard (RI_spec): when deprived of A instead, it must avoid C. Otherwise it is just trying the unfamiliar item.

    What went wrong, and what it taught

    Uncertainty-seeking mimics wanting

    A pilot active-inference agent passed zero-shot revaluation (0.77) while knowing nothing about C: under need, its objective favored the unknown option. Any test like this needs a specificity guard and a control agent that must fail it.

    Devaluation can be passed without graded wanting

    “Don't eat what you're full of” scores well on devaluation. Only the need sweep showed that feedforward PPO is nearly indifferent between slightly and badly needed nutrients.

    Fixed training budgets can void a result

    At 10M steps, the central predictions were formally uninterpretable. Training should run to a competence target, not a fixed step count. The fix here was one extension, disclosed in advance, with a commitment to no further extensions.

    Don't hold controls to impossible standards

    The blind control can't know which item it needs, so its low choice rate was predictable. Gating it on competence left P2 formally uninterpretable, even though its result was never in doubt.

    The first scoring of P8 was wrong

    The novelty prediction was first marked “supported” on a raw difference (109 vs 107 exposures). Scored with the planned test it is not supported (Holm p = 1.0).

    The original project's measures didn't measure desire

    Of the six v1 measures, three were passed by agents with no desire at all, two depended on scoring bugs, and one was never computed. That audit is why the project was reframed.
