Held-out-need experiment (v3) · Oct 10–11, 2026 · branch wanting-vs-habit

Can an agent learn to want something it has never needed?

The earlier experiment said learned agents can't. But that test was close to rigged against them: nothing told an agent which item fixes which need. This one gave learning its best possible shot. Every prediction, threshold and scoring rule was fixed in writing before any agent was trained.

Sometimes. But not reliably, and not on average.

The best-shot agent (20 independently trained copies) learned almost perfectly to go for the nutrients it had needed during training. Then it faced a need it had never had. The average copy moved only a little toward the remedy, and still mostly picked something it needed less.

A few copies did it almost perfectly; nearly half showed essentially none. By the rule written in advance, the headline result is inconclusive. My own forecast scored worse than if I had spread my bets evenly.

How the test works

A small grid world with seven nutrients. Agents are rewarded for keeping every nutrient near a healthy level, and they learn by trial and error (reinforcement learning).

The set-up

During training, six nutrients regularly ran low. The seventh, H, never did. The agent saw H items and sometimes ate them, but eating H always over-filled it, so H was mildly unpleasant. That's like the salt that Berridge's rats had tasted but never needed.

Offered, at equal distance: H vs j

Then H is made very low for the first time. An agent that wants what it needs goes for H straight away, even though H was never useful before. A creature of habit sticks with j.

Three checks that catch fakes

Several non-wanting strategies can look like wanting, so a pass needs all three:

  • 1
    Specific. It doesn't pick H when a different nutrient is the one running low. (Catches "try the odd item whenever needy".)
  • 2
    Directional. It doesn't pick H when H is over-full, which is also a never-seen state. (Catches "go for whatever looks unusual".)
  • 3
    Seeking. It actually prefers H over the less-needed j, rather than just no longer avoiding H. (Catches "only avoid what I'm full of".)

Each test uses 200 choice probes per copy, with no reward during probes, so the agent can't learn the answer on the spot. A score of 1 means it switches perfectly with need; 0 means need makes no difference.

The most interesting clue secondary · not controlled

The same agents were also tested with a brand-new nutrient whose code they had never seen. They went for it far more than for H, the nutrient they knew but had never needed.

A possible explanation (a hypothesis, not a finding): the agents' ability to read a need generalizes. What blocks H is something they learned about H itself: eating it was always mildly bad. Berridge's rats overrode exactly that kind of learned dislike of salt the first time they needed salt. These agents mostly didn't. Even at equal need, the best shot picks H only 1% of the time. This probe had no specificity or directional checks, so a "go for the unfamiliar when needy" strategy could produce the same numbers. Testing it properly needs a new pre-registered experiment.

What it means

1

Learning can produce something that looks like wanting for a brand-new need, but not reliably. In 4 of 20 best-shot copies (pre-set test; plausible range 6–44%), a trained network went for the remedy for a need it had never had, and only when that specific need was low. That needed a built-in link between each item and the need it fixes. Without that link, or with only two trained needs, nothing transferred.

2

My earlier conclusion was too strong as a blanket rule, and right about the typical case. "Learned agents can't revalue a new need" is contradicted by those copies. But the average agent, even when built favorably, revalued the new need at about a third of the strength of familiar ones, and still preferred a less-needed familiar item.

3

The sharper question now is about overriding learned dislikes, not learning versus planning. The clue above suggests the obstacle isn't a failure to generalize. It may be that a new need doesn't override what the agent already learned about the item. Animals do override it.

4

How much this matters: modestly. It is one toy world and one learning algorithm. The durable contribution is a test that seven different fake-wanting strategies can't pass, and a warning: an agent that tracks its familiar needs almost perfectly (0.96 here) can still say very little about whether it wants something new. If behavioral evidence of "wanting" in AI systems is ever taken seriously, it should be tested on needs the system never trained on.
